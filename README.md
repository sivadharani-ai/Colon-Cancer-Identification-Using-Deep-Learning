# Colon Cancer Identification Using Deep Learning

## Project Overview

This project is a Machine Learning and Flask-based web application developed to identify colon cancer using patient medical data. The system processes input features, applies a trained machine learning model, and predicts whether colon cancer is detected.

## Technologies Used

* Python
* Flask
* NumPy
* Pandas
* Scikit-learn
* Machine Learning
* Pickle

## Features

* Medical data preprocessing
* Feature scaling using StandardScaler
* Random Forest Classification model
* Model evaluation and accuracy measurement
* Flask-based web interface
* Real-time cancer prediction

## Project Workflow

1. Load Colon Cancer Dataset
2. Data Preprocessing
3. Handle Missing Values
4. Feature Scaling
5. Train-Test Split
6. Random Forest Model Training
7. Model Evaluation
8. Save Trained Model
9. Develop Flask Web Application
10. Predict Colon Cancer Status

## Results

The trained machine learning model analyzes patient input features and predicts whether colon cancer is detected. The system provides results through an easy-to-use web interface.
